1. 한눈에 보기

대상 기간에 보호나라 보안공지 7건(#2549~#2555)이 게시됐고, 조회한 CISA 악용 확인 목록(KEV) 판본 기준으로 같은 기간 신규 등재 3건이 확인됐습니다. 이 가운데 특정 제품·버전·CVE를 지정하지 않은 일반 공지 2건은 제외했고, Cisco 1건은 두 수집원에 중복돼 한 건으로 묶었습니다. 결과적으로 이번 호 점검 대상은 7건이며 이 중 5건은 실제 악용이 확인됐습니다.

경계 구간 장비 세 계열이 동시에 터졌습니다. Citrix NetScaler(CVE-2026-88771, CVSS 9.5)는 추가 기능 설정 없이 기본 구성 전체가 영향을 받고 인증 없이 명령 실행이 가능합니다. Cisco Catalyst SD-WAN Manager(CVE-2026-76504, CVSS 9.8)는 인증 없이 admin 권한으로 접근되고, Fortinet FortiMail(CVE-2026-104286, CVSS 9.8)은 IBE 기능이 켜져 있으면 인증 없이 파일을 쓸 수 있습니다. 세 건 모두 벤더가 실제 악용을 확인했고 KEV 연방기관 기한(9/30 · 10/3 · 10/4)은 모두 지났습니다.

국내 장비 침해 사례가 공지됐습니다. 파이오링크가 PAS-K 구버전 취약점으로 원격 명령이 실행되고 채굴 악성코드가 설치된 사례를 확인했다고 밝혔습니다(KISA #2553 · 벤더 공지 2026-09-29). CVE 번호가 부여되지 않은 건이어서 KEV에는 나타나지 않습니다. 공공사업 환경에 L4/L7 스위치로 도입된 경우가 많아 사용 여부 확인이 먼저 필요합니다.

지난 호 미확정 항목 하나가 확정됐습니다. 지난 호에서 "KEV 신규 등재로 보고되나 조회한 판본(9/25자)에 없음 — 등재일 미확정"으로 남겼던 Citrix CVE-2026-88771 · CVE-2026-88772의 KEV 등재일이 2026-09-27로 확인됐습니다(기한 9/30, 이미 경과). 이번 주 보호나라 #2550이 같은 계열 8건을 함께 공지해, 이번 호에서 처음 상세히 다룹니다.

※ 조회한 KEV 판본은 2026-10-01자입니다. 대상 기간 마지막 사흘(10/02~10/04)은 이 판본 이후 구간이라 이번 호에서 확인하지 않았습니다. 위 "신규 3건"은 10/01까지 확인된 수치이며 대상 기간 전체의 확정 건수가 아닙니다. 자세한 내용은 5항에 적었습니다.

3. 공지별 조치 방법과 조치 확인 방법

3-1. Citrix NetScaler ADC · Gateway 8건
CVE-2026-88771 외 7건

긴급 · CVSS 9.5(v4.0) · 악용 확인 | KISA #2550(9/29 게시) · KEV 등재 9/27(기한 9/30)
상황 Citrix가 NetScaler ADC·Gateway 취약점 8건을 한 번에 공지했습니다. 이 중 두 건이 KEV에 등재된 악용 확인 건입니다.
· CVE-2026-88771(CVSS 9.5) — 입력값 검증 미흡으로 인증 없는 공격자가 임의 명령을 실행합니다. 벤더가 밝힌 전제 조건은 "모든 NetScaler ADC·Gateway 배포 (기본 구성 / 추가 기능 불필요)"입니다. 추가 설정 없이 해당된다는 뜻이므로 이 계열을 운영 중이면 예외를 기대하기 어렵습니다.
· CVE-2026-88772(CVSS 9.5) — 메모리 오버플로로 원격 코드 실행 또는 서비스 거부. 전제는 DTLS 설정 활성화이며, 벤더는 "VPN vServer에서는 기본 활성"이라고 적었습니다.
벤더 진술 — "Exploits of CVE-2026-88771 and CVE-2026-88772 on unmitigated NetScaler deployments have been observed."
나머지 6건은 전제 조건이 구성에 따라 갈립니다 — 88773(HTTP/SSL 가상 서버), 88774(HTTP URL 기반 정책 표현식), 88775(Gateway 또는 AAA 가상 서버), 88776(Oracle 유형 LB 가상 서버), 88777(비HTTP L7 기능), 88778(Enhanced ISN Generation 비활성 상태의 TCP 구성).
CVSS는 88773이 9.3, 88775~88778이 8.8, 88774가 7.0입니다(전부 v4.0, 벤더 값).
조치 벤더 권고 버전 이상으로 올립니다. 8건이 같은 빌드로 함께 해소됩니다.
· NetScaler ADC · Gateway 14.1-73.37 이상
· NetScaler ADC · Gateway 13.1-64.23 이상
· NetScaler ADC FIPS 14.1-73.37 FIPS 이상
· NetScaler ADC FIPS · NDcPP 13.1-37.279 이상
벤더 문구 — "Cloud Software Group strongly urges affected customers of NetScaler ADC and NetScaler Gateway to install the relevant updated versions as soon as possible."
· CVE-2026-88778은 버전 상향만으로 끝나지 않습니다. 벤더는 해당 구성에 Enhanced ISN Generation 관련 TCP 설정 변경을 함께 적용하라고 안내합니다. 정확한 설정 절차는 벤더 문서를 확인하십시오 — 설정 키 이름은 [미확인]으로 두었습니다.
· 버전 상향 외의 공식 우회책은 벤더 공지에 기재되어 있지 않습니다.
조치 적용 확인 ① 구성 전제를 먼저 분리합니다 — 88771은 기본 구성 전체 해당이므로 운영 중이면 무조건 대상입니다. 88772는 DTLS 활성 여부(VPN vServer는 기본 활성), 88775는 Gateway·AAA 가상 서버 존재 여부, 88776은 Oracle 유형 LB 존재 여부를 각각 확인합니다.
② 실행 중인 빌드 문자열이 위 값 이상인지 확인합니다. 설치 패키지가 아니라 동작 중인 빌드 기준입니다.
③ HA 쌍이면 양쪽 노드 모두 확인합니다. 클러스터 구성이면 전 노드를 개별 확인합니다.
④ FIPS·NDcPP 장비는 일반 빌드와 수정 버전이 다릅니다. 장비 유형을 먼저 확인한 뒤 해당 계열 값과 비교하십시오.
⑤ [미확인] 빌드 확인용 정확한 CLI·콘솔 경로, 그리고 업그레이드 후 기존 세션 종료가 필요한지를 벤더 공지에서 확인하지 못해 싣지 않습니다. 악용 확인 건이므로 세션·자격증명 후처리 필요 여부를 Citrix 지원에 확인하실 것을 권합니다.
침해 흔적 확인 [미확인] — 확보한 벤더 공지(CTX697096)에 침해 지표나 탐지 절차가 기재되어 있지 않습니다. 확인 방법이 없다는 것이 침해가 없다는 뜻은 아닙니다.
이미 악용이 관측된 건이므로, 패치 전 기간에 대해 관리·인증 가상 서버 접근 기록, 신규 생성 계정·세션, 장비발 외부 통신을 함께 확인하시기 바랍니다 (벤더 IoC 아님 — 공격 유형에서 도출한 점검 착안점입니다). 벤더가 로그 문자열이나 명령을 제공하지 않아 구체적인 명령은 싣지 않습니다.
출처 Citrix 보안 공지 CTX697096 · KISA 보호나라 보안공지 #2550(2026-09-29) · CISA KEV(dateAdded 2026-09-27, CVE-2026-88771 · CVE-2026-88772)

3-2. Cisco Catalyst SD-WAN Manager
CVE-2026-76504

긴급 · CVSS 9.8 · 악용 확인 | KISA #2554(10/1 게시) · KEV 등재 9/30(기한 10/3)
상황 API 세션 기반 인증 관리의 결함으로 인증 없는 원격 공격자가 admin 사용자 권한으로 시스템에 접근할 수 있습니다.
벤더 요약 — "A vulnerability in the API session-based authentication management of Cisco Catalyst SD-WAN Manager could allow an unauthenticated, remote attacker to access an affected system with privileges of the admin user."
CVSS 9.8(CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H), Cisco 등급 Critical.
벤더 진술 — "In September 2026, the Cisco PSIRT became aware of active exploitation of this vulnerability." CISA는 9/30 KEV에 등재했고 연방기관 기한 10/3은 이미 지났습니다.
SD-WAN 오케스트레이터는 하위 장비 전체를 관리하는 계층입니다. 여기가 뚫리면 관리 대상 네트워크 전체가 영향권에 듭니다.
조치 계열별 First Fixed Release 이상으로 올립니다(벤더 표 기준, KISA #2554 표와 일치).
· 20.9 → 20.9.10.1  ·  20.12 → 20.12.8.2  ·  20.15 → 20.15.6.1
· 20.18 → 20.18.4.1  ·  26.1 → 26.1.2.1  ·  26.2 → 26.2.1
· 20.9 미만은 개별 패치가 없습니다. 벤더와 KISA 모두 "해결 버전으로 마이그레이션"으로 안내합니다.
우회책은 없습니다. 벤더 문구 — "There are no workarounds that address this vulnerability." 다만 On-Prem 배포 환경의 완화책으로 "인터넷 등 비보안 네트워크로부터의 시스템 접근을 제한"하라고 안내합니다. 완화책은 패치를 대체하지 않습니다.
조치 적용 확인 ① 실행 중인 Catalyst SD-WAN Manager 릴리스가 해당 계열의 First Fixed Release 이상인지 확인합니다. 계열(20.9 / 20.12 / 20.15 / 20.18 / 26.1 / 26.2)별로 기준값이 다릅니다. 다른 계열의 값과 비교하지 않도록 주의하십시오.
② 클러스터 배포면 전 노드를 개별 확인합니다. 일부 노드만 상향되면 경로가 남습니다.
③ On-Prem이면 관리 인터페이스가 실제로 외부에서 도달 가능한지를 외부에서 확인합니다. 설정값만 보지 말고 도달 여부를 확인하십시오.
④ [미확인] 실행 버전 확인용 정확한 명령이나 콘솔 경로를 공식 문서로 확인하지 못해 싣지 않습니다.
침해 흔적 확인 벤더가 공식 확인 방법을 제시합니다.
· serviceproxy-access.log 와 vmanage-server.log 를 점검합니다.
· 미확인·비인가 IP에서 들어온 j_security_check 관련 기록을 확인합니다. URI 인코딩 변형(%6a_security_check)도 함께 봅니다.
· viptela-reserved- 로 시작하는 사용자명에 대한 요청을 확인합니다.
결과가 비어 있어도 침해가 없다는 뜻은 아닙니다. 공격 성공 시 admin 권한을 얻는 건이므로 장비 내부 로그만 보지 말고 방화벽·프록시 등 외부 로그를 교차 확인하시기 바랍니다.
출처 Cisco 보안권고 cisco-sa-sdwan-webauth-xr8beuuU · KISA 보호나라 보안공지 #2554(2026-10-01) · CISA KEV(dateAdded 2026-09-30, CWE-177)

3-3. Fortinet FortiMail — CVE-2026-104286

긴급 · CVSS 9.8 · 악용 확인 | KEV 등재 10/1(기한 10/4) · 보호나라 공지 대상 아님
상황 경로 조작과 NULL 바이트 처리 결함이 겹쳐, 인증 없는 공격자가 조작된 HTTP/HTTPS 요청으로 시스템에 임의 파일을 쓸 수 있습니다. 공격 표면은 IBE(Identity Based Encryption) 기능입니다.
CVSS 9.8(AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H). 벤더 벡터에 E:P(악용 코드 존재)와 RC:C(확인됨)가 포함돼 있습니다.
벤더 진술 — "This has been reported to be exploited in the wild, customers are urged to apply the workaround below."
중요 — IBE를 쓰지 않으면 해당하지 않을 수 있습니다. 다만 구성 여부를 실제로 확인해야 판단할 수 있습니다.
조치 계열별 수정 버전 이상으로 올립니다(벤더 PSIRT 기준).
· FortiMail 8.0 (영향 8.0.0~8.0.1) → 8.0.2 이상
· FortiMail 7.6 (영향 7.6.0~7.6.6) → 7.6.7 이상

5. 집계 기준과 참고 사항

집계 기준 — KISA는 게시판 게시일, CISA KEV는 dateAdded 기준입니다. 대상 기간은 2026-09-28 00:00 ~ 10-04 24:00(KST)입니다. 기간 내 KISA 공지 7건(#2549~#2555)이며, 게시판 총 2,555건·최상단 일반행 #2555와 일치합니다. 상단 고정 공지 5건 중 1건(nttId=72207)은 일반 목록 #2555와 동일 게시물이어서 한 건으로 계수했고, 나머지 4건은 게시일이 2026-07-16 이전으로 기간 밖입니다. 페이지 1의 최하단 일반행이 #2546(9/22)으로 기간 시작보다 이르므로, 기간 내 게시물은 페이지 1에 전부 포함됩니다.

조회한 KEV 판본 기준 기간 내 신규 등재는 3건이며, CVE 중복 1건(CVE-2026-76504 — KISA #2554 ↔ KEV)을 하나로 묶어 점검 대상 7건을 본문에 실었습니다. 이 중 2건(Apple · Fortinet)은 KEV에서만 확인된 항목으로, 보호나라만 봤다면 놓쳤을 건입니다.
